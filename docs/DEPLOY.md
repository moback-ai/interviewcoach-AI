# Deploy

**Developers do not deploy from this repository.**

1. Open a PR into `develop` and pass **Security** CI  
2. Request **DevSecOps** review and merge  
3. Ask DevSecOps for production **build + deploy** when ready  

Deploy workflows run only from **`moback-ai/devsecops-platform`** (DevSecOps only).

See [DEVSECOPS.md](DEVSECOPS.md).
